# Meal prep

A simple recipe tracker: recipe cards with macros per portion, and a shopping list that combines ingredients across the recipes picked for the week.

## Use it
- On your computer: double-click `index.html`.
- On your phone: turn on GitHub Pages for this repo and open the link.

## Add or change a recipe
All recipes live in `recipes.js`. Copy an existing recipe block, change the details, save, then commit and push.

## Add a photo
1. Put the image in the `images` folder, e.g. `images/pesto-pasta.jpg`.
2. In `recipes.js`, set that recipe's `image` to `"images/pesto-pasta.jpg"`.

## Good to know
- Ticked shopping items and "this week" picks are saved in the browser you're using, so your phone and laptop keep separate lists.
- Macros use typical supermarket label values, so treat them as close estimates.
